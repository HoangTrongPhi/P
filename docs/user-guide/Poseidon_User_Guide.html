Giới thiệu tổng quan

Poseidon gom các thao tác “dọn dẹp asset” thường phải làm tay hoặc bằng script rời rạc vào một ứng dụng duy nhất, chạy nhanh và an toàn.

Poseidon giải quyết vấn đề gì?

  • Tên file không theo chuẩn (wood_planks_basecolor.png thay vì T_WoodPlanks_D.png).
  • File FBX lưu đường dẫn tuyệt đối từ máy artist (D:\artist\…) nên mất texture khi import.
  • File .blend tham chiếu texture nằm rải rác, không mang đi được.
  • Bộ asset bàn giao từ artist (thường trên Google Drive) không rõ mesh nào dùng texture nào.
  • Cần pack ORM, đổi định dạng / kích thước texture, tìm file trùng hoặc texture không dùng.

Batch Renamer

Ctrl+1

Đổi tên hàng loạt asset theo chuẩn Unreal Engine 5, Unity, hoặc theo quy tắc tuỳ chỉnh — có xem trước và Undo.

Cách sử dụng

  1. Kéo thả thư mục (hoặc file) vào tab, hoặc bấm mở thư mục. Bật Subfolders để quét cả thư mục con.
  2. Lọc loại file: All, Meshes, Textures, PSD.
  3. Thêm quy tắc (Rules). Các quy tắc chạy lần lượt từ trên xuống, có thể bật / tắt, đổi thứ tự, xoá:
    • Preset: Unreal Engine 5 — SM_, SK_, T_*_D / _N / _R / _M / _ORM.
    • Preset: Unity — PascalCase, _Albedo / _Normal / _MaskMap.
    • Search & replace — tìm / thay thế, hỗ trợ Regex ($1, $2) và Match case.
    • Prefix / Suffix — thêm tiền tố / hậu tố, có tuỳ chọn bỏ qua tên đã có sẵn.
    • Change case — snake_case, camelCase, PascalCase, UPPER_CASE, lowercase, kebab-case.
  4. Bảng xem trước cập nhật ngay: Current name → New name kèm trạng thái OK, Skipped, Collision (trùng tên), Invalid. Bật Hide unchanged để chỉ xem dòng thay đổi.
  5. Bấm Apply để đổi tên. Nếu cần quay lại, bấm Undo.
An toàn: Poseidon kiểm tra trùng tên trước khi ghi, đổi tên hai pha khi có hoán đổi (a → b, b → a) và lưu lịch sử vào .rename_history.json trong thư mục để Undo.
Ứng dụng: chuẩn hoá tên cả thư viện asset theo naming convention của studio / engine chỉ trong vài giây, tránh lỗi gõ tay và dễ dàng hoàn tác.

FBX Doctor

Ctrl+2

Tìm và sửa đường dẫn texture tuyệt đối / hỏng bên trong file FBX (Binary 7.x và ASCII) mà không cần mở phần mềm 3D.

Cách sử dụng

  1. Kéo thả file FBX hoặc thư mục chứa FBX vào tab.
  2. Chọn một file để xem bảng Texture paths: Object / field, Path in file, loại đường dẫn (Kind) và trạng thái On disk (found / missing).
  3. Chọn chế độ sửa (Mode):
    ModeKết quả
    RelativeĐường dẫn tương đối từ FBX tới vị trí thật của texture.
    StripChỉ giữ tên file (wood.png).
    CollectCopy texture vào thư mục con cạnh FBX (mặc định textures/) và trỏ tới đó.
  4. Tuỳ chọn thêm:
    • Extra texture folders / Also search the parent folder — nơi tìm texture theo tên file (vd. thư mục ../Textures).
    • Rewrite every path — sửa cả đường dẫn đã hợp lệ, không chỉ đường dẫn tuyệt đối / hỏng.
    • Guess paths for missing textures — texture không tìm thấy được gán <subfolder>/<name>.
    • Keep .fbx.bak backup — giữ bản sao lưu (khuyến nghị bật).
  5. Áp dụng cho Selected file hoặc All files, kiểm tra preview rồi bấm Fix. Có thể khôi phục từng file từ .fbx.bak.
Mẹo: xuất báo cáo HTML / CSV để gửi lại cho artist danh sách texture bị thiếu.
Ứng dụng: khắc phục lỗi “mất texture” kinh điển khi import FBX từ máy khác vào UE5 / Unity / Blender; giữ nguyên byte các phần không chỉnh sửa nên file vẫn an toàn.

Blender Packer

Ctrl+3

Điều khiển Blender 5.0+ chạy ngầm (headless) để phân tích và gom toàn bộ file phụ thuộc của một scene .blend.

Cách sử dụng

  1. Poseidon tự tìm Blender (biến môi trường BLENDER_PATH, Registry, thư mục cài đặt mặc định). Nếu không thấy, bấm Browse để chỉ định blender.exe.
  2. Kéo thả file .blend hoặc mở bằng nút chọn file.
  3. Chọn Operations:
    Thao tácTác dụng
    Analyse onlyChỉ báo cáo các file phụ thuộc, không thay đổi gì.
    ConsolidateCopy file ngoài vào //textures và remap đường dẫn.
    Make paths relativeChuyển đường dẫn tuyệt đối sang tương đối.
    Unpack embedded filesXuất ảnh đã pack ra //textures.
    Pack everything into the .blendNhúng toàn bộ vào một file .blend duy nhất.
    Bundle a zipĐóng gói .blend kèm textures/ và assets/ thành file zip.
  4. Output: ghi đè file gốc (Blender giữ bản .blend1) hoặc Save as a new file.
  5. Bấm chạy, theo dõi thanh tiến trình. Khi xong, mục Report liệt kê từng data-block, đường dẫn và trạng thái (found / missing / packed).
Ứng dụng: chuẩn bị file .blend để bàn giao, lưu trữ hoặc gửi render farm — đảm bảo người nhận mở ra không bị thiếu texture (ảnh hồng).

Asset Previewer

Ctrl+4

Xem nhanh mesh 3D và texture (kể cả HDR / EXR / PSD / TIFF) ngay trong ứng dụng, không cần mở DCC.

Cách sử dụng

  1. Kéo thả mesh, texture hoặc cả thư mục. Danh sách asset hiện bên trái, chuyển giữa dạng list và thumbnails, gõ Filter để lọc.
  2. Chọn một asset để xem:
Viewport 3D (FBX, OBJ, glTF, GLB) Xoay / zoom / pan bằng chuột · lưới nền, trục pivot · Reset camera · thông số Triangles, Vertices, UV sets, Materials, Bones, kích thước và đơn vị file · danh sách vật liệu & texture · phát animation (chọn clip, tốc độ) · ánh sáng: Studio, HDR/EXR tuỳ chọn, Exposure, Key light · Save view as PNG nền trong suốt.
Texture viewer Fit to view / Actual size (100%) · zoom, pan · điều chỉnh Exposure và Gamma cho ảnh HDR · thông tin kích thước, định dạng, kiểu dữ liệu.
  1. Bật Reload when it changes on disk để tự tải lại khi file (và texture của model) thay đổi — tiện khi vừa export từ DCC vừa xem.
Ứng dụng: kiểm tra nhanh asset nhận được (đúng scale, đúng trục, đủ texture, đếm poly) trước khi import vào engine; chụp ảnh preview cho tài liệu hoặc thư viện asset.

Pipeline Tools

Ctrl+5

Bộ 6 tiện ích xử lý texture và mesh, chọn bằng thanh tab nhỏ phía trên.

Công cụCách dùngỨng dụng
ORM packer Thả các map …_ao, …_roughness, …_metallic (hoặc chọn từng file), đặt tên output (vd. T_Asset_ORM.png), chọn PNG / TGA. Tick nếu input là gloss / smoothness (sẽ được đảo ngược). Map thiếu dùng giá trị mặc định (AO 1.0, Roughness 0.5, Metallic 0). Gộp 3 map xám thành 1 texture R=AO, G=Roughness, B=Metallic — giảm số texture sample, chuẩn của UE5.
Texture sets Chọn thư mục → texture được nhóm theo material dựa vào hậu tố (_BaseColor, _N, _Roughness…). Xem mỗi set thiếu map nào, pack ORM hàng loạt cho các set đủ điều kiện. Kiểm tra độ đầy đủ của bộ texture PBR và pack ORM cho cả thư viện một lần.
Converter Thêm texture / thư mục. Chọn định dạng (Same as source, PNG, TGA, JPG, DDS uncompressed + mips), Max size, Snap to power of two, Flip green channel, hậu tố và thư mục output. Có Preview trước khi ghi. Resize texture cho mobile / LOD, ép kích thước lũy thừa 2, chuyển normal map DirectX (UE) ↔ OpenGL (Unity, Blender).
Meshes Thả file mesh hoặc chọn thư mục → bảng Triangles, Vertices, UV sets, Materials, Normals, kích thước, đơn vị, trục Up; có thể đặt ngân sách tam giác. Audit poly budget và lỗi kỹ thuật (thiếu UV, sai đơn vị / trục) cho cả loạt mesh mà không cần viewport.
Duplicates Chọn thư mục → file được nhóm theo kích thước rồi băm XXH3-128 song song. Kết quả là các nhóm file giống hệt từng byte; Show in Explorer để xử lý. Tìm file trùng lặp để dọn dung lượng project / repo.
Unused textures Chọn thư mục → đọc mọi FBX, OBJ/MTL, glTF, GLB và so với texture trên đĩa. Tick Read .blend files để tính cả scene Blender (cần Blender 5.0+). Phát hiện texture “mồ côi” không mesh nào dùng, để xoá bớt trước khi bàn giao.
Báo cáo: hầu hết công cụ có nút xuất HTML / CSV để chia sẻ kết quả.

Recipes

Ctrl+6

Ghép nhiều công cụ thành một quy trình (recipe) chạy lặp lại được — trong ứng dụng hoặc từ dòng lệnh.

Cách sử dụng

  1. Đặt tên recipe (vd. My import recipe), hoặc chọn Templates… để bắt đầu từ mẫu có sẵn.
  2. Add step… để thêm bước. Các loại bước:
    BướcMô tả
    RenamePreset UE5 / Unity / Custom (có thể copy rule đang bật từ tab Renamer).
    Fix FBXRelative / Strip / Collect, tuỳ chọn ghi lại texture không tìm thấy.
    Pack ORMPNG / TGA, tuỳ chọn ghi đè file ORM có sẵn.
    Convert texturesĐịnh dạng, Max size, Power of two, Flip green.
    Inspect meshesThống kê mesh, ngân sách tam giác.
    Find unused / duplicatesTìm texture không dùng (tuỳ chọn đọc .blend) / file trùng.
  3. Sắp xếp bước bằng Move up / down, lưu recipe thành file .json.
  4. Kéo thả thư mục cần xử lý, bật Dry run để Preview run (không ghi gì), rồi Run for real. Recipe dừng lại nếu một bước lỗi.
  5. Bấm Copy command line để lấy lệnh chạy không cần giao diện:

poseidon.exe --recipe ue5-prep.json D:/Assets/Props --dry-run --report report.json

Mã thoát: 0 = mọi bước thành công, 1 = có bước lỗi, 2 = sai tham số / recipe không hợp lệ. Trong cmd dùng start /wait poseidon.exe … để chờ kết quả.

Ứng dụng: chuẩn hoá quy trình nhập asset của cả team (“mọi asset mới phải đổi tên UE5 → sửa FBX → pack ORM”), tích hợp vào build script / CI.

Dashboard

Ctrl+7

Trả lời câu hỏi “Bộ bàn giao này có gì?” — thống kê số lượng và dung lượng asset.

Cách sử dụng

  1. Kéo thả thư mục asset (ổ local hoặc đường dẫn Google Drive như G:\Shared drives\…).
  2. Xem các chỉ số tổng: Assets, Meshes, Textures, Packages, Total size.
  3. By asset type: phân bổ theo Mesh / Texture / Scene / Source, kèm chi tiết theo định dạng.
  4. By package: biểu đồ cột chồng theo thư mục con. Chỉnh Package level (1–3 cấp thư mục), chuyển chỉ số Files / Size, chuyển Chart / Table.
  5. Bấm vào một package để đi sâu vào trong, nút ↖ Up one folder để quay ra. Xuất báo cáo HTML / CSV.
Lưu ý: Dashboard chỉ đọc tên và kích thước file, nên có thể xem cả một Shared drive mà không tải file nào về máy.
Ứng dụng: đánh giá nhanh quy mô và cấu trúc bộ asset của artist / outsource trước khi xử lý, phát hiện package quá nặng, lên kế hoạch dung lượng.

Asset Matcher & Kit Assembler

Ctrl+8

Tự động xác định texture set nào đi với mesh / material slot nào, sau đó đóng gói thành bộ kit sạch cho UE5 hoặc Unity.

Dashboard→Asset Matcher→Kit Assembler→Project UE5 / Unity

Asset Matcher

  1. Mở thư mục bàn giao (hoặc một package). Với Google Drive, Poseidon ước tính dung lượng mesh cần đọc và hỏi lại nếu vượt 64 MB.
  2. Mỗi mesh (FBX, OBJ, glTF, GLB) và mỗi material slot nhận một texture set, điểm tin cậy 0–100 và lý do:
    Trạng tháiÝ nghĩa
    ExactFile mesh lưu đường dẫn tới chính texture của set.
    LikelyThắng rõ ràng theo tên material / tên mesh.
    ReviewNhiều set điểm gần bằng nhau hoặc bằng chứng yếu — bạn tự chọn.
    No matchKhông set nào đủ điểm.
  3. Lọc To decide để xem các slot cần xử lý; Accept best for reviews chọn ứng viên tốt nhất cho mọi slot Review. Mỗi slot có dropdown để đổi set thủ công (đánh dấu ✎).
  4. Panel bên phải hiển thị ứng viên, map của set và đường dẫn texture trong mesh; khi không chọn slot, nó liệt kê Unused texture sets và Textures without a map suffix.
  5. Refresh để match lại mà vẫn giữ lựa chọn; Save manifest ghi asset_manifest.json; Export ra HTML / CSV.

Kit Assembler

Bấm Assemble kit… (hoặc Assemble kit from manifest… trong Ctrl+K):

  • Destination: thư mục project, vd. <UE project>\Content\Environment.
  • Naming: Unreal (SM_…, T_…_D/_N/_ORM), Unity (WallCorner_BaseColor.png) hoặc giữ tên gốc.
  • Tuỳ chọn: Pack ORM maps, Relink texture paths in meshes, Keep package folders, Include unconfirmed matches, Overwrite.
  • Bảng kế hoạch (dry run) hiển thị trước; bấm Assemble để ghi, sau đó Show kit. File kit_manifest.json ghi lại kết quả.
An toàn: thư mục bàn giao chỉ được đọc — không file nào bị đổi tên, ghi đè hay xoá. Kết quả đọc mesh được cache nên lần quét sau chỉ đọc file mới / thay đổi.
Ứng dụng: biến một thư mục bàn giao lộn xộn của artist thành bộ asset sạch, đúng naming, đã pack ORM và nối sẵn texture — sẵn sàng import vào engine.
